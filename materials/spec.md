## 路演 PPT 页面(P1–P8,Unit u-mtp7537q-i2f8xo)

### P1 封面 hero(深底渐变)
- 上:队伍「411 · 伴学计划」小徽标(白字胶囊)
- 主标题:RUC Agent
- 副标题:把对话与微信里的安排,自动整理成日程与待办
- Slogan:不让任何一件重要的事被吞没
- 下:成员「贺奕锴 · 孙若瑜 · 冯冠瑀」+「校园日程智能助手 Demo」
- 装饰:五个页面小圆钮(对话/计划/日程/待办/我的)排成流程图,末端日历图标;底纹为半透明圆形,不用位图

### P2 痛点(为什么)
核心信息:学生日程散落,靠人脑与侥幸。
- 三张卡片(左中右,各带图标):
  1. 安排散落在各处 —— 微信群公告、随口一句话、文件传输助手里的通知,转瞬即忘
  2. 撞车靠肉眼发现 —— 时间重叠、DDL 迫近,发现时已经来不及
  3. 精力被高估 —— 硬塞式排期不考虑状态,拖延与熬夜成为常态
- 底部结论条:缺的不是「又一个日历」,而是一个会提取、会排期、会心疼你的助手
- 右侧配一张 shot_input 对话截图小样(可选,若空间允许)

### P3 一句话方案 + 产品全景
核心信息:一个「先确认、再入库、越用越懂你」的日程助手。
- 顶部一句话:像发微信一样说安排 → AI 提取为卡片 → 你确认后写入日程/待办
- 5 个页面截图缩略卡(shot_input / shot_planner / shot_schedule / shot_todos / shot_mine,1440×900→约 172×108)
  每个缩略图上放页面名小标签:对话 · 计划 · 日程 · 待办 · 我的
- 下方一行箭头串联:录入 → 排期建议 → 时间轴 → 待办池 → 画像/记忆/设置
- 诚实注脚:AI 可选、规则兜底,全部数据只在本地 data/

### P4 核心工作逻辑(架构流程,纯矢量图)
核心信息:四层隔离 + 两条提取通路 + 人机确认环。
- 流程主链(从左到右,6 个节点圆角块):
  ① 输入:对话页直接说 / 微信自动读取转发
  ② 提取:规则预筛(≥10字+时间地点线索)→ AI 可选(OpenAI/DeepSeek/Kimi)→ 规则兜底
  ③ 待采纳:结构化卡片进对话流,你点「采纳到日程/待办/忽略」才入库
  ④ 存储分层:结构化事实(todos/courses)↔ 证据层 ↔ 动态画像(精力/负载/压力/处境)↔ 长期记忆(偏好/性格)
  ⑤ 规划:AI 选择性提议 + 能量引擎校验(空闲块/硬软线/24h 精力曲线 EMA),完成概率推演,低概率给风险与拆分建议
  ⑥ 反馈:完成待办点「轻松/正常/吃力」→ 校准精力曲线 → 影响下次排期
- 闭环回弯箭头从 ⑥ 回到 ④/⑤,标注「越用越懂你」
- 底部三标签:冲突提醒 · 挡箭牌话术 · 本地隐私(仅 data/)

### P5 真实演示 ①:对话即录入(左文右图)
核心信息:自然语言 → 待采纳卡片 → 确认入库。
- 文案要点(左侧 bullet 卡):
  - 说人话:「周六下午3点到体育馆打篮球」直接识别(含中文数字时间)
  - 「下周一上午9点前交作业」→ 作业 + 硬截止;无时间 → 待办池兜底不丢
  - 每条识别结果带类别/地点/截止/耗能,先经你确认
- 右侧大图:shot_input.png(约 560×350,白卡片圆角+阴影+浏览器顶栏样式)
- 图上叠两个标注针:「AI 提取完成 · 待采纳」「采纳到日程 / 待办 / 忽略」
- 底部一个输入样例条:「周四晚上7点参加社团例会,在二教401 → 周四 19:00 · 地点 · 类别」

### P6 真实演示 ②:计划页 —— 排期与风险(右文左图)
核心信息:AI 只挑现在值得做的;能量引擎保证排得下。
- 左侧大图:shot_planner.png
- 右侧要点:
  - 今日能量环 + 24h 精力曲线(07–23 点,EMA 自动校准)
  - 「值得现在做」的选择性排期:远 DDL 不提前刷屏;重新规划/跳过
  - 完成概率推演:低概率 → 风险提示 + 拆分/降标建议
  - 排期永不落在当前时间之前;冲突/超载红色预警
- 底部一行三 mini 数据事实:软线 DDL 自动顺延 1–2 天 · 拖拽即改排期 · 翻页不重复提议

### P7 真实演示 ③:微信自动提取 + 挡箭牌(左右对照)
核心信息:不打开 App,日程也会自己出现;被硬塞时帮你体面说不。
- 左卡「微信自动提取」:
  - 转发到文件传输助手(或指定会话/全部会话)→ 自动进时间轴,带 📲 微信标签
  - 实时监听 1.5s 轮询 + 回读补档,「加入前」的消息也能补进;消息去重
  - shot_schedule.png 缩略带标注「微信来源自动入库」
- 右卡「智能挡箭牌」:
  - 粘贴外部任务(团建/聚餐)→ 评估当前负载 → 生成「婉拒/待定/接单」话术,一键复制
  - 冷静不制造焦虑
- 底部原则条:闲聊消息只进活动日志、绝不污染日程(预筛保护隐私与成本)

### P8 完成度 · 亮点 · 致谢(收尾)
- 左「本次完成度(诚实)」清单:
  - 可运行 Demo:python server.py → 127.0.0.1:8000,零安装
  - 纯 Python 标准库后端 + 原生 HTML/CSS/JS 前端(无框架)
  - 65 项单元 + 端到端测试通过
  - 微信 4.x 提取、AI 网关、画像/记忆、能量排期全链路可用;AI 失败自动回退规则
  - 数据与 API Key 只在本地
- 右「亮点 ×3」:①先确认后入库、绝不替你做决定;②规则+AI 双引擎,没 Key 也全功能;③画像/记忆/精力闭环,越用越懂你
