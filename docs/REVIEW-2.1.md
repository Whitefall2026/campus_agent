## v2.1.2 Excel 识别补丁

任务表支持“日期”作为计划完成日回退、纵向合并日期、计划时长(h)及小时单位、P0/P1/P2 和勾选完成。明确截止值优先；建议时段不充当截止时刻，普通空白日期不自动向下继承。工作簿存在任务表头时，辅助页不进行自然语言待办提取；多表按任务名称与截止去重，任一任务表标记完成则跳过对应重复项。

模型要求正时长，零时长任务保留为 1 分钟并提示，不改变任务模型。合并日期公式无缓存时对整组提示重算；不执行工作簿公式。新增边界与 HTTP 导入测试只使用虚构任务。

原文件只读核对：31 条任务的名称、日期、优先级、时长逐项匹配，每日计划与明细的任务集合一致。隔离 HTTP 验证预览不保存、确认后字段正确、再次上传标记重复；原文件哈希未改变。明细状态公式缺缓存的行被提示跳过，所有任务已从每日计划读取。工作簿和任务正文未写入此报告、测试夹具或发布资源。

全量测试原有 4 项用例在 23 点后要求当天仍能排程，未修改的 v2.1.1 同样失败。API 集成测试固定排程入口为当天上午 9 点，使测试不依赖运行时钟；生产排程及系统时钟保持不变。v2.1.2 本地实际运行 148 项、147 通过、1 项原生 Mac 锁测试跳过；Python 编译、JS 语法和差异检查通过。安装包及对应平台的原生构建结果以 Release 和 CI 实际日志为准。
